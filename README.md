## Development

### Monsters & Memories

I’ve been a UI developer on [Monsters & Memories](https://monstersandmemories.com/) since October 2026.

- [MnM on Mac](https://github.com/seathasky/MnM-on-Mac) · **Open source (MIT).** I maintain this community launcher for installing, updating, and playing the game on macOS through Wine.
